One question format for every exercise

Visual reference for docs/question-design.md. Every reading, listening, writing, speaking and vocabulary question — in lessons, practice, skill checks, story quizzes, level tests, placement and review — uses the same card: the same five parts in the same order, one type scale, one listen control, and one footer. Only the answer area changes with the question type. Interface text below is the app's real Uzbek copy (Uzbek → English course).

1. Anatomy

Five parts, always in this order. Parts 3 and 4 are the only ones that change between question types.

  1. 1
    HeaderSkill chip (Reading, Listening, Writing, Speaking or Vocabulary) on the start side; counter on the end side (“Savol 3 / 8”, or an “Unscored” tag for speaking practice); progress bar underneath. Same in lessons, practice, tests and review.
  2. 2
    Instruction18 px / 650, plain text, never inside a coloured box and never a big heading. One sentence that says what to do.
  3. 3
    Prompt panelThe thing being asked about, on the green panel. Top row: language label (12 px caps) and, when there is audio, the listen pill. Prompt text 26 px / 650 (21 px when longer than ~60 characters). Optional support line 15 px muted (translation hint, gap meaning). Audio-only prompts show one large play button instead of text.
  4. 4
    Answer areaOne of five answer types — choice list, word bank, match board, speaking control, or reveal box. All answer text is 17 px / 600, every target is at least 44–52 px tall.
  5. 5
    FooterDivider, then: start side holds one secondary text action before answering (Clear, Can’t listen?, Show transcript, Read the story again) and the feedback after answering; end side holds the primary button (Check → Next question → See results). On phones the button goes full width.

One way to do each thing

  • Listen: the outlined “Tinglash” pill at the top of the prompt panel. Audio-only questions use the large play button in the panel. No other audio buttons.
  • Fallbacks (show transcript, can’t listen, sample answer, read story again) are always the footer text action, never a second button.
  • Primary button always bottom-end, always one. Choice questions answer on tap; word banks and speaking use “Javobni tekshirish”.
  • Feedback always in the footer: ✓ To‘g‘ri! or ✗ To‘g‘ri javob: … at 15 px, plus the choice or line turns green/red.
  • Word banks everywhere get the same dashed answer line, the same tray, and “Tozalash” as the footer action (lessons have no Clear today).
  • Start-aligned everywhere — no centred cards (review) or start-aligned buttons (speaking) as exceptions.
  • Logical CSS (inline-start/end), so Arabic mirrors automatically.
