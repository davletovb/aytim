# Aytim

Aytim is a language-learning app for Uzbek, English, Russian, Modern Standard Arabic, Turkish, and German. Learn in any direction between the six languages through the website or Telegram Mini App.

[Open Aytim](https://aytim.behruz-davletov.workers.dev/)

## Features

- Short, mixed-skill lessons covering reading, listening, writing, speaking, and vocabulary.
- Eight learning levels with placement assessments and level tests.
- Short stories, focused exercises, and spaced-repetition vocabulary practice.
- Audio playback, speaking practice, and optional reading aids for Arabic and Russian.
- Telegram sign-in and cross-device progress sync.
